# karansadiora.com

My personal site: one page over a 3D neuron that fires as you read, built with Vite and Three.js. It also hosts my eye-typing app, [EyeSpeak](https://karansadiora.com/eyespeak/).

## Development

Run `npm install`, then `npm run dev` to serve it at `http://localhost:5173`. `npm run build` writes the site to `dist/`, and every push to `main` deploys it to Cloudflare.
